## Procedural note
This repository is meant to serve two purposes.

1. A place to store the onboarding instructions for getting the robotic arm software set up.
2. A place to store *links* to other documentation in git repositories about certain topics.

This repository is **NOT** meant to serve any of the following purposes.

1. A central location to store all documentation of code for the robotic arm.

   The correct location for this information is **with the code**, in it's own git repository.
   Then, include a link to that documentation here.

3. Any other purpose not listed.
